# Portal Access Guide

## 1. Admin Portal (For Building Owners & Managers)

**Access:** https://login-system-lime.vercel.app/admin/login

This is your command center. From here, you can:

- **Manage Buildings** — Add new buildings, view building details, generate QR codes
- **Manage Tenants** — Add, edit, or remove tenants from your buildings
- **Manage Staff** — Add security guards, staff members, and assign them to buildings
- **View Visitors** — See all visitor records across all your buildings
- **Track Payments** — Monitor tenant payments and outstanding balances
- **Generate Reports** — Get insights on visitor traffic, staff attendance, and more

### How to Log In:
1. Go to the Admin Portal address above
2. Enter your email address
3. Enter your password
4. Click "Sign In"

---

## 2. Security Portal (For Security Personnel)

**Access:** https://login-system-lime.vercel.app/security/login

Your security team uses this portal to:

- **See who is currently in the building** — Live list of all checked-in visitors
- **View visitor details** — Name, phone, purpose of visit, check-in time
- **Manually check out visitors** — If a visitor forgets to check out
- **Monitor daily visitor traffic** — Statistics and daily logs

### How Security Staff Use It:
1. Security guard logs in at the start of their shift
2. The dashboard shows all current visitors in real-time
3. When a visitor arrives, they scan the QR code (see Visitor section below)
4. The visitor appears on the security dashboard immediately
5. Security can click on any visitor to see full details
6. At the end of the day, security can see the complete visitor log

---

## 3. Staff Portal (For Building Employees)

**Access:** https://login-system-lime.vercel.app/staff/login

Building staff use this portal to record their attendance:

- **Clock In** — Start of shift
- **Clock Out** — End of shift
- **View Work Hours** — See how many hours worked
- **Attendance History** — View past attendance records

### How Staff Use It:
1. Staff member opens the portal on their phone or computer
2. Logs in with their credentials
3. Taps "Clock In" when starting work
4. Taps "Clock Out" when finishing work
5. Their hours are automatically calculated and recorded

---

## 4. Visitor Check-in (For Building Visitors)

**Access:** Via QR Code at building entrance

This is the heart of your visitor management system. Visitors do not need to download any app or create any account.

### How It Works:

**Step 1: Visitor Arrives**
- Visitor sees the QR code displayed at the building entrance

**Step 2: Visitor Scans QR Code**
- Using their smartphone camera, they scan the QR code
- This opens the check-in page automatically

**Step 3: Visitor Fills In Details**
- Full Name
- Phone Number
- ID Number (National ID or Passport)
- Purpose of Visit (who they are visiting and why)

**Step 4: Visitor Checks In**
- They tap "Check In"
- They receive a confirmation on their screen
- Their visit is now recorded in the system

**Step 5: Security is Notified**
- The visitor immediately appears on the Security Dashboard
- Security can see all their details

**Step 6: Visitor Leaves**
- When leaving, visitor scans the same QR code again
- The system recognizes them and shows "Check Out" button
- They tap "Check Out" and their visit is complete

# Setting Up Your Buildings

## Generating QR Codes for Each Building

Each building needs its own QR code. Here's how to set it up:

1. Log into the **Admin Portal**
2. Go to **Buildings**
3. Click **Add Building** (or select an existing building)
4. Fill in the building details:
   - Building Name
   - Address
   - Number of floors (optional)
5. Click **Save**
6. The system automatically generates a unique QR code
7. Click **Download QR Code** or **Print QR Code**
8. Display the printed QR code at your building entrance

### Where to Display the QR Code:
- Reception desk
- Main entrance
- Security booth
- Elevator lobby
- Any visitor entry point

# Daily Operations

## Morning Routine

1. **Security Guard** logs into the Security Portal
2. Dashboard shows a fresh start with no visitors (or overnight visitors if applicable)
3. As visitors arrive and scan the QR code, they appear on the dashboard

## During the Day

- **Visitors** scan QR code and check in themselves
- **Security** monitors the dashboard for all visitor activity
- **Staff** clock in when they arrive, clock out when they leave
- **Admins** can check reports and manage the system as needed

## End of Day

1. Security can see the complete log of all visitors for the day
2. Any visitors who forgot to check out can be manually checked out
3. Staff attendance is automatically recorded
4. Reports are available in the Admin Portal

# Frequently Asked Questions

**Q: What if a visitor doesn't have a smartphone?**
A: Security can manually register the visitor through their dashboard.

**Q: What if the internet goes down?**
A: The system has offline capability. Data will sync automatically when connection is restored.

**Q: Can I see visitors from last week or last month?**
A: Yes, all visitor records are stored and can be viewed in the Admin Portal under Visitors or Reports.

**Q: How do I add a new security guard?**
A: Log into Admin Portal → Staff → Add Staff → Select role as "Security" → Assign to building.

**Q: Can one security guard monitor multiple buildings?**
A: Admin users can see all buildings. Security guards see only their assigned building.

**Q: Is the data secure?**
A: Yes, all data is encrypted and stored securely in the cloud.
